# uzbek-game-audio

Pronunciation audio for **So'z Sayohati**, the Uzbek word game on [imidnotes.com](https://www.imidnotes.com/p/games.html).

Each clip is one Uzbek word, phrase or sentence from the 50 Study Uzbek lessons.
The game plays them through jsDelivr: `https://cdn.jsdelivr.net/gh/mehrisha-lang/uzbek-game-audio@main/audio/<id>.mp3`
